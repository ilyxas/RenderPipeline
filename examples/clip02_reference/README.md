# clip02 reference

This directory contains compact evidence retained from the legacy `clip02_blender_kit`. It is not a runnable copy of that project.

`legacy_anim_metrics.json` records output statistics from the prepared legacy animation and can seed baseline comparisons. It is not ground truth and must not be consumed as input motion by the new solver.

The source video, `.blend`, GLB, NPZ animation arrays, render outputs, venv, and legacy scripts are intentionally excluded. When a development stage needs a source asset, it must be registered externally by content hash and read without modification.
