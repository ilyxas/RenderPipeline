# Статус проекта — начинать отсюда

Папка для передачи контекста между сессиями (Ilya + Claude). В новом чате читать в таком порядке:

1. [STATUS.md](STATUS.md) — что работает, что нет, какой солвер использовать, где лежат ассеты.
2. [TODO.md](TODO.md) — подтверждённые проблемы с доказательствами и предложенным решением, по приоритету.
3. [sessions/](sessions/) — журнал сессий: что сделано, что обнаружено, какие решения приняты и почему.

Правила ведения:

- В конце сессии добавить файл `sessions/YYYY-MM-DD.md` и обновить `STATUS.md` и `TODO.md`.
- В `TODO.md` — только то, что подтверждено данными (цифры, кадры, логи), с пометкой уровня:
  *подтверждено* / *гипотеза*. Догадки без проверки помечать явно.
- Закрытый пункт `TODO.md` переносится в журнал сессии, где он был закрыт, со ссылкой на коммит.
- Если что-то здесь расходится с кодом — прав код, файл исправить.
